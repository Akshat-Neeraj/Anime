📥 MAL / AniList Import & Export
📤 Export to MAL-compatible XML
Round-trips with MyAnimeList's own import — anime/OVA/ONA/special go in the anime list, manga/manhwa/manhua/novel/webtoon/comic go in the manga list. Other types (movies, K-drama, games, etc.) aren't part of MAL's format and are left out of these two files.
How to export from MAL: MyAnimeList → Profile → Export → Export Anime/Manga List → download XML
How to export from AniList: anilist.co/settings → Apps → Export → download JSON
🔍 Duplicate Scanner
Scans your whole library for near-duplicate titles — catches typos, alternate spellings, and re-adds you might have forgotten about. Same title with a different type (e.g. the manhwa vs. the anime) is intentionally NOT flagged.
⚠ Sync Conflicts
These titles had unsynced local changes when the last pull came in. The cloud version was kept for each — pick "Keep mine instead" on any of these to restore what this device had, then sync again to push that choice everywhere.
🗑 What should I drop?
Titles in Watching that are both stale (21+ days untouched) AND barely started (under 30% progress, or 0 episodes logged if the total is unknown) — the ones most likely already abandoned in practice.
🗑 Trash
Deleted entries stay here for 30 days before they're gone for good.
